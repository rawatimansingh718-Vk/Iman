1. Introduction

The purpose of this assignment was to evaluate the performance of my Web Programming portfolio website using Google Lighthouse. I performed performance tests, reviewed the audit recommendations, and compared the results from two Lighthouse runs.

This report presents the performance scores, important metrics, identified issues, and the improvements to consider for making the website faster and more efficient.

4. Optimization Areas

Based on the Lighthouse recommendations, I identified the following optimization techniques as relevant areas to improve the website.

  1. Reduce render-blocking resources: Review CSS and JavaScript loading so that important page content can be displayed without unnecessary delays.
  2. Improve image delivery: Compress large images, use suitable image formats, and provide appropriate image dimensions.
  3. Improve browser caching: Use suitable cache policies for static resources so returning visitors do not need to download the same files unnecessarily.
  4. Review DOM structure: Keep the HTML structure organized and avoid unnecessary elements.
  5. Improve layout stability: Provide image dimensions and reserve space for content to reduce unexpected layout movement.

These are optimization opportunities identified from the audit. Only describe an item as completed if you actually applied that change to your website.
